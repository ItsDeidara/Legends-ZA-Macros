## Set up
Follow this video to learn how to set up the reset, Once you are positioned on the teleporter, start the macro
https://youtu.be/TE26SuSrQj4

## Notes
You may have to change the wait times, depending on your load times. Mine is 6 seconds before the "Investigate" prompt to use the teleporter

## Requirements
Pokemon Automations set up. (capture card not needed for this macro)
https://pokemonautomation.github.io/
